## 概要

**ImageCrate** は、Webページ上に埋め込まれた画像から必要なものだけを快適に選び出し、一括保存するためのブラウザ拡張機能です。

外部のサーバーやサードパーティ依存を一切使わず、ブラウザ標準の Web API と Manifest V3 だけで構築されています。広告フィルター、拡大プレビュー、タッチジェスチャー、端末内フォーマット変換（JPEG / PNG / WebP）、ZIP一括保存、iOSの共有シート連携（AirDrop / ファイル保存）などを備えています。

## Chromeへ読み込む

1. Chrome 116以上で `chrome://extensions` を開き、デベロッパーモードをONにします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリ内の **`extension/`** を指定します。
3. 通常のWebページを開き、拡張アイコンからImageCrateを開きます。開くだけではChromeの追加アクセス許可を要求しません。
4. 既存の許可や元ページの一時アクセスでプレビューを自動表示します。追加許可が必要な画像は、一覧上部の配信元ごとのボタンでまとめて表示できます。そのボタンを押したときにChromeへ許可を求めます。画像を選択して「選択N件を保存」を押します。プレビュー未読込でも選択・元形式保存はできます。

更新済みのコードを試す場合は、保存が終わってから古い作業タブを閉じ、`chrome://extensions` のImageCrateの再読み込みボタンを押してください。その後、元ページで拡張アイコンを押して作業タブを開き直します。作業途中の状態復元を試すときは、拡張の再読み込みではなく**作業タブだけを再読み込み**します。

## Safari (iOS / macOS) で動かす

1. `npm run safari:convert` を実行します（`safari/ImageCrate` にXcodeプロジェクトを生成・同期します）。
2. Xcodeで `safari/ImageCrate/ImageCrate.xcodeproj` を開きます。
3. 実機（iPhone / iPad）またはシミュレータをターゲットに選び、「Run（Cmd+R）」でビルド・実行します。
4. iOSの設定 → Safari → 拡張機能で「ImageCrate」を有効化します。
5. SafariでWebページを開き、拡張機能メニュー（パズルピースまたは「ぁあ」アイコン）からImageCrateを起動します。
6. モバイル環境では自動的に **ZIP保存（共有シート連携）** が選択され、保存ボタンを押すだけでiOS標準の共有シート（ファイルに保存 / AirDrop 等）から一括保存できます。

※ `safari/` のプロジェクトは `extension/` の各ファイルを直接参照しているため、JavaScript/HTML/CSSの変更はChromeとSafariの両方に自動反映されます。

実サイトを使わず試せる [合成ページと5つの試用課題](docs/UX-COMPLETION.md#本人試用の準備) を用意しています。

画面下の「保存先 → 変更」で、保存する場所・まとめるフォルダ名・保存形式を指定できます。名前は最初はページ名です。空欄ならページ名を使い、使えない記号・長い名前を調整した実際の名前をプレビューします。

設定は「設定を適用」で反映します。キャンセル・閉じる・Escapeでは、編集中の名前・形式・選んだフォルダを取り消し、適用前の設定を保ちます。適用しただけでは画像の保存を開始しません。

「次の作業でもこの保存先を使う」は初期ONです。OFFを適用すると、次回用の保存方法とフォルダ参照を忘れ、新しい作業ページはChromeのダウンロード先から始まります。現在の作業ページや中断分の再開に必要な参照は保持するので、OFFにしても現在の保存先は変わりません。キャンセル・Escapeでは記憶設定も変わりません。

保存形式は **元の形式 / JPEG（.jpg）/ PNG（.png）/ WebP（.webp）**。JPEG・PNG・WebPは端末内で画像自体を変換します。JPEGの透明部分は白背景、PNGとWebPは透明部分を保持します。対応するアニメーションは1コマの静止画になります。SVGは単色の矩形だけで描かれた限定形式に対応し、一般のSVGやAVIFのプレビュー・変換は行いません。対応形式は[画像処理の制限](docs/SECURITY-HARDENING.md#対応する画像)を参照してください。同じ形式を選んだ画像も再エンコードし、画質やメタデータが変わる場合があります。アニメーション・元データを保持する場合は「元の形式」を選んでください。形式は作業ページ内で保持し、新しく開いた作業ページは「元の形式」から始まります。

**変換して保存するときは、どちらの保存先でも作業タブを開いたままにしてください。** 画像の配信元だけへのアクセス許可をChromeに求めます。失敗しても元形式へ勝手に切り替えず、中断として表示します。結果が確定した中断分の再試行は、開始時に選んだ形式と保存先を使います。書き込みやChromeの受付が未確定の間は再試行できません。

- **Chromeのダウンロード先**（初回設定）：`ImageCrate/<指定した名前>/` に保存。「元の形式」では追加のサイトアクセス許可は不要です。
- **選択したフォルダ**：「フォルダを選ぶ」で任意の場所を選び、その中の `<指定した名前>/` に直接保存。次回への記憶がONなら、適用した保存方法と最後のフォルダをこの端末で覚えます。書き込み許可が必要なら設定から再確認してください。pickerから絶対パスは取得できないため、画面には選んだフォルダ名を表示します。新しい作業ページのまとめる名前は、そのページ名から始まります。

選択フォルダへの保存では、保存する画像の配信元だけへのアクセス許可をChromeに求めます。許可しなくても選択は残り、Chromeのダウンロード先に戻して保存できます。**この方式では保存が終わるまで作業タブを開いたままにしてください。** 再読込・終了時は警告し、再読込後は結果が確定した中断分を再試行できます。書き込み結果が分からない場合は保存先を確認し、新しい保存として準備してください。Chromeのダウンロード履歴には載りません。

同名フォルダはそのまま使い、同名ファイルは上書きせず別名で保存します。「今回の保存先」と形式は保存開始時に固定され、「中断分を再試行」も同じ設定を使います。「中断分を新しい保存として準備」では、中断した画像だけを別の先・形式で新しく保存できます。通常の選択は保持し、新しく保存する前に中断分の対象件数を表示します。取り消すと通常の選択保存へ戻ります。

ビルド・APIキー・アカウント登録は不要です。実行時の外部ライブラリ・サーバーは使いません。

## 実装済み

- ページ内の画像、レスポンシブ画像候補、遅延読み込み属性、CSS背景、open shadow DOMと同一オリジンframeの画像を取得。
- URLで重複を除き、同じimg/pictureの別候補をまとめて表示。「大きく確認」「確認・他N候補」からプレビューの拡大・等倍表示・前後移動・候補比較ができ、画像ごとに選択できます。プレビューは縮小した静止画です。等倍表示は生成したプレビューの1ピクセルを画面の1ピクセルで表示し、元画像の全画素を表示する機能ではありません。
- 検索、最小寸法、形式で絞り込み。「広告らしい画像を除外」は初期ONで、縦横比3:1以上・短辺200px未満・GIF・標準広告サイズ・広告配信ネットワーク・トラッキングタグをまとめて除外しつつ、元ページの縦長漫画（Webtoon等）や高解像度コンテンツは保護して残します。元ページの寸法で概算し、プレビュー後は検査した実寸法・形式を使います。適用中の条件はチップで確認・解除でき、プレビューで確認した情報は「確認した情報で条件を更新」で再適用します。除外しても選択は保持し、「選択済み」から確認・保存できます。
- 最初は未選択。「表示中を選択」、個別選択、全解除。「選択済み」は絞り込みや候補グループにかかわらず、前の取得分を含む全選択を表示します。
- 選択分だけをChromeのダウンロード先、または選んだフォルダへ保存。まとめるフォルダ名を指定可能。実際の完了・中断を追跡し、中断分を再試行。
- 保存形式を指定し、JPEG・PNG・WebPへ実変換。保存形式と実際の拡張子を対応させ、変換済みファイルも完了・中断を追跡。
- 成功分は選択解除。作業タブの再読み込み後も選択・表示条件・表示モード・開閉状態・戻り位置を復元します。再スキャンは現在のDOMから候補を入れ替え、選択した画像は保持。「今回追加」から新しい候補を確認できます。
- 500候補・12000要素、または処理量の区切りを超える場合は「続きの候補」で進めます。候補を追加できない区切りでも前の候補と選択は残ります。スキャン全体の上限に達すると、取得済みの候補を残して終了します。
- altによる選択名、寸法・保存状態の関連付け、キーボード用の「保存操作へ移動」と「画像一覧へ戻る」、拡大表示を閉じた後のフォーカス復帰を用意。
- アイコンと短いラベル、選択枠、保存進捗で状態を表示。詳しい説明は「使い方」から確認。動きを減らすOS設定に対応。

## 権限とプライバシー

- `activeTab` / `scripting`: 拡張アイコンを押したページのDOMを一時的に調べます。全サイト常時アクセスは要求しません。
- `downloads`: 利用者が選んだメディアの保存と、当拡張が開始したdownload IDの状態確認。
- `alarms`: 保存結果や一時予約の後片付けを照合する必要がある間、作業タブを閉じた後も確認を再開するための内部アラームを使います。外部通信や定期通知のためには使いません。
- `storage`: ページURL・画像候補・選択・処理状況をChromeのsession storageに保持します。作業タブを閉じると元ページのURL・タイトル、候補・選択・表示履歴を取り除き、結果未確定の保存や後片付けに必要なjob情報は確定まで保持します。「元の形式＋Chromeのダウンロード先」は受理済みの残りを継続し、終了後に消去します。session情報はブラウザ終了で消去されます。
- 保存結果のsession記録には実ファイル名だけを保持し、Chromeが返す保存先の絶対パスは残しません。保存の照合時にはChromeの生の情報を一時的に使います。名前やページの文字列自体に個人情報が含まれる場合はあります。
- 適用した保存方法と選んだフォルダの参照は端末内のIndexedDBに保持します。次回用の記憶は設定でOFFにでき、同じ作業・再試行に必要な参照とは分けて管理します。OFFや設定取消では保存済みファイル・Chromeの権限を変更しません。まとめるフォルダ名と保存形式は新しい作業ページへ引き継がず、ページURLや画像URLを永続設定へ保存しません。
- インストール時に、すべてのサイトを読み書きする権限は求めません。`optional_host_permissions` の `http://*/*` と `https://*/*` は、あとから特定の画像配信元だけを許可できるようにするための宣言です。利用者が許可するまで、拡張はそのサイトへアクセスしません。
- 拡張アイコンから開くだけでは、追加のアクセス許可を要求しません。開いたページと同じ配信元の画像は、アイコンを押したときの一時アクセスでプレビューします。別の配信元は、一覧上部の配信元ごとのボタンを押したときに、その配信元だけをChromeへ要求します。同じ配信元の画像は、その1回の許可でまとめて表示できます。
- 選択したフォルダへの保存、ZIP、JPEG / PNG / WebPへの変換では、保存ボタンを押した操作の中で、選んだ画像の配信元だけをまとめて要求します。断られても選択は残ります。「元の形式」をChromeのダウンロード先へ保存するときは、追加のサイトアクセスを要求しません。
- プレビューは初期状態からONです。すでに許可した配信元、または元ページの一時アクセスで、画面に近い画像を自動取得します。作業ページを開き直しても、同じ許可の再同意は求めません。一時アクセスは、開いたままの元ページと同じ配信元の収集済み画像に限り、元ページの移動・終了時には使いません。アクセスできない配信元があっても、画像の選択と「元の形式＋Chromeのダウンロード先」での保存はできます。許可した配信元は、Chromeの拡張機能の設定から取り消せます。
- プレビュー・変換・選択フォルダへの取得は、ブラウザのログイン状態を使う場合があります（`credentials:include`）。Refererは送信せず、HTTPリダイレクトは追跡しません。許可を自動で他の配信元へ広げません。埋め込みdata画像も自動で端末内処理し、Chromeのhost許可を要求しません。
- 解析・テレメトリ・アカウント・クラウド送信なし。メディア取得時はその配信元への通信が発生します。
- 候補URLは認証用query等を含む可能性があります。session内に留め、Git・ログ・不具合報告へ貼らないでください。フィードバックは合成データで再現します。
- サイトの認証情報・Cookieを独自に取得する処理はありません。Chrome自身のdownloadはブラウザの既存セッションに従います。

元形式は、元画像に含まれる撮影者・位置情報などのメタデータも保持します。変換は画像を描き直しますが、完全なメタデータ除去・匿名化の機能ではありません。保存済みファイルやChromeのダウンロード履歴・キャッシュは、拡張のsession後片付けとは別に残ります。データの扱いの詳細は [プライバシーとデータ保持](docs/PRIVACY.md)、ストアに掲載する説明は [プライバシーポリシー](docs/PRIVACY_POLICY.md) を参照してください。

セキュリティ・プライバシーを含む問い合わせ先: [deeple+imagecratestaff@inkboxmail.com](mailto:deeple+imagecratestaff@inkboxmail.com)。報告方法は [SECURITY.md](SECURITY.md) を参照してください。

## 制約

- 取得は今DOMに存在する内容です。自動スクロールやページ全体の巡回は行いません。スクロール・表示後に再スキャンしてください。
- 閉じたshadow DOM、別オリジンiframe、ページ内blob画像には未対応。CSS擬似要素の背景・canvasの描画は対象外。
- 元ページの寸法情報は密度指定等で実ファイルの画素数と異なる場合があります。検査した元画像の寸法が分かるまでは「寸法未確認」とし、最小寸法を指定しても残します。プレビュー生成後は元画像の寸法で絞り込みを更新できます。縮小プレビューの寸法は元画像の寸法として使いません。
- 認証・Referer制限・URL失効などにより、プレビューや保存に失敗することがあります。元ページで見える画像すべての保存は保証しません。
- 選択フォルダへの直接保存では、別の配信元へのリダイレクトやサイト制限で取得できない場合があります。アクセスを自動で広げず中断として表示します。Chromeのダウンロード先へ切り替え、画像を選び直して新しく保存する方法も使えます。
- 「元の形式」は内容を変換しません。Chromeへの保存ではChromeが返す画像MIME、選択フォルダへの保存では画像MIME・既知の先頭署名から拡張子を補います。拡張子不明の候補で判別できなければ `.img` と形式不明表示を使います。拡張子が付いたことは、デコードや正常な画像であることの保証ではありません。形式指定時は実変換した形式の拡張子を使います。ZIP化は未実装です。
- 形式変換は元ファイル32MiB以下・出力64MiB以下・2400万画素以下・縦横16384px以下です。取得から保存まで1試行120秒、30秒無進捗で中断します。プレビューは入力8MiB・20秒・2400万画素・縦横8192px以下で、サムネイルは最大辺384px、拡大用は2048pxまでの静止画を生成します。一般のSVG・AVIF・検査できない構造はプレビューと変換を拒否し、元形式の明示保存を使えます。
- 選択フォルダへの元形式保存は1試行128MiB・120秒まで。作業ページで行う保存は、同じ保存全体で入力・出力を別々に各512MiB、開始から15分、同じ画像の試行は初回を含め3回までです。再試行や作業ページの再読み込みで予算は戻りません。Chrome自身が元URLを取得する保存では、同じ容量・時間を観測基準として確認し、超過を観測すると取消を要求します。書き込み前の厳密上限や即時停止を保証する方式ではありません。
- 未確定の書き込み・保存受付・画像処理の予約を、時間が過ぎたことだけで空き枠に戻しません。確認できない処理が残ると新しい処理を拒否することがあります。保存先とChrome履歴を確認してください。ブラウザの再起動でsession内の一時状態は消えますが、保存先の既存・未完成ファイルは自動削除しません。
- これらは拡張が受け入れるデータと管理する処理の上限です。ネットワーク上の総転送量、Chrome内部の一時メモリ、OS/native処理の即時停止、通常Chrome保存の書き込み前の厳密上限は保証しません。詳しくは[安全対策と上限](docs/SECURITY-HARDENING.md)を参照してください。

- Chrome設定・Web Store等、拡張を実行できないページは対象外。
- 1回の取得は最大500候補・12000要素に加えて、文字・候補の処理量でも区切り、続きの取得に対応します。DOM変更や取得情報の期限切れでは先頭から再スキャンし、選択済みは保持します。埋め込み画像には別途容量制限があります。
- 作業タブは各拡張で4つまで。元タブが移動した場合はそのページでアイコンを押し直してください。
- 選択は作業タブごとに500件まで。作業タブ全体で候補情報6MiB・session情報8MiBの予算を設け、容量不足は通知します。選択を減らすか使い終わった作業タブを閉じて再操作してください。保存される画像ファイルの容量制限とは別です。
- 作業状態はブラウザのsession内に限ります。ブラウザ終了や拡張自体の再読み込みをまたぐ永続復元は保証しません。
- Chromeの保存受付は30秒を区切りに照合します。30秒後に受付・保存結果が不明な保存を、確定した中断として自動再試行することはありません。受付未確定・取消待ち・通常Chrome保存の進行中jobを再確認する内部アラームはChrome116互換の1分間隔を使い、背景処理やOSスリープで実行が遅れる場合があります。30秒以内の結果表示を保証するものではありません。

## 開発・検証

Node.js 22以上:

```sh
npm test
npm run check
npm run package
# ブラウザテストのみ開発依存が必要
npm ci
npm run test:browser
npm run test:ux
npm run test:security
# 公式Chrome for Testing116実行ファイルを指定した最低版の基本確認
CHROME_EXECUTABLE="/path/to/chrome" npm run test:compat
```

ブラウザテストはインストール済みのChromeを、個人プロファイルとは別の一時プロファイルで起動します。テストコピーだけに合成ページの配信元（localhost）へ必要なhost権限を付け、収集・UI・保存を検証します。配布用のmanifestに、全サイトへ常時アクセスする `host_permissions` は入れません。実機のフォルダ選択と、ツールバーのアイコンから付く一時アクセスの確認は、自動テストとは別に行います。`CHROME_CHANNEL`でPlaywrightのchannelを変更できます。

全14項目の対応表、試用手順と今回の到達点は [docs/UX-COMPLETION.md](docs/UX-COMPLETION.md)。検証範囲と残件は [docs/QA.md](docs/QA.md)、体験と状態の設計は [docs/DESIGN.md](docs/DESIGN.md)、現行の画像処理・上限・保証範囲は [docs/SECURITY-HARDENING.md](docs/SECURITY-HARDENING.md) を参照してください。Chrome116は公式テスト版で基本動作を確認しました。提示した操作試用について本人から「試して問題なし」と回答がありました。これは以前の基本確認・試用の結果です。今回追加した配信元同意、縮小プレビュー、処理上限の理解や操作を本人が確認した結果とは扱いません。今回変更後のChrome116追試範囲はQAを参照してください。実OS pickerの利用有無・実スクリーンリーダーは未確認です。
