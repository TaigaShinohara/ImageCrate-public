# 操作カタログ — ImageCrate

実装の前に作る正本。ここに無い操作を CLI へ場当たりで足さない。追加するときは先にこの表へ登録し、狙いを添える。

分類: **機械可** = CLI（`npm run agent`）や既存の開発コマンドで実行できる / **B（画面案内）** = 機械は対象と手順の提示まで、最後の操作は人間が作業ページで行う / **C（人間専用）** = OS やブラウザの対話が必須で、自動化を偽装しない。

対象レベルの前提: 拡張の実データ（候補・選択・保存ジョブ）はブラウザの `chrome.storage.session` 内にあり、CLI からは触れない。CLI が扱うのはパッケージ（リポジトリ）と、CLI 専用状態（`.agent/`）だけである。
