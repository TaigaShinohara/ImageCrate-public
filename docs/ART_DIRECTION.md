# ImageCrate アート方針（Art Direction）

この文書は ImageCrate の UI デザインにおける正本である。UI の追加・修正を行う際は必ず開始時に本書を参照し、完了時に照合する。

---

## 1. アプリ全体の意味

- **一番見せたいもの（主役）**: ページから収集した「画像そのもの」と「今何枚選んでいるか・保存できるか」という状態。
- **どう思ってほしいか（狙う気持ち）**: 「余計な広告やノイズに邪魔されず、必要な画像だけを迷わず見極めて、安心して手元に保存できる」という軽快さと信頼感。
- **主な手段**: 無彩色の静かなキャンバス上に画像を並べ、ユーザーの意思決定（選択・絞り込み・保存）に関わる操作だけをバイオレットのアクセントで際立たせる。

---

## 2. 世界の言葉（雰囲気）

### 目指す雰囲気（キーワード3つ）
1. **静謐な作業台（Calm Workbench）**: 画像の色や細部を正しく見極めるため、背景とカードは純白〜淡いクールグレーで統一し、UI 自身の主張を抑える。
2. **明快なアクセント（Crisp Violet）**: 選択状態、主アクション（保存）、アクティブな絞り込みなど「ユーザーの操作と結果」だけをバイオレット（`#6351d9`）で明確に示す。
3. **軽やかな輪郭（Crisp & Tactile）**: 1px の繊細な境界線と統一された角丸で領域を整理し、重い影に頼らず軽やかな階層を作る。

### やらない雰囲気
- **装飾的なグラデーションや強いネオン色**: 画像の視認性・色評価を妨げるため使わない。
- **文字だらけの説明的 UI**: 初心者にも直感的に伝わるよう、アイコン・ピル・短いラベルで表現し、補足は折りたたみ（`details`）へ逃がす。
- **過度なドロップシャドウの乱用**: 浮かせる必要があるモーダル・スティッキーフッター・オーバーレイボタンに限定する。

## 3. 色の性格

| 役割 | 性格（明度・彩度・色相） | コンセプトとの結びつき |
|---|---|---|
| **キャンバス背景** | 高明度・極低彩度のクールグレー（`#f7f8fb`） | 白いカードや写真の輪郭を自然に浮かび上がらせ、長時間の選別でも目が疲れない。 |
| **サーフェス（面）** | 純白（`#ffffff`）および極淡グレー（`#fafafc`） | 画像サムネイルや操作パネルの土台。清潔感と整理された印象を作る。 |
| **文字（インク）** | 深いチャコールネイビー（`#252631`）と落ち着いたグレー（`#656976`） | 真っ黒（`#000`）より柔らかいコントラストで可読性を保ち、主従をつける。 |
| **アクセント** | 鮮やかながら深みのあるバイオレット（`#6351d9`）＋極淡ティント（`#f0edff`） | 拡張機能アイコンの世界観と一致し、「選択」「保存」「有効な絞り込み」を一目で識別させる。 |
| **境界線** | 淡いクールグレー（`#e0e3eb`） | 要素を明確に区切りつつ、視覚的なノイズにならない繊細さを保つ。 |
| **危険・警告** | 落ち着いたクリムゾン（`#ab3541`） | エラーや中断など、注意が必要な状態だけを冷静に伝える。 |

## 4. 形の言語

- **角丸の階層**:
  - 小（タグ・バッジ・小ボタン）: `6px`〜`8px`
  - 中（標準ボタン・入力欄・ツールバー・パネル）: `10px`〜`12px`
  - 大（モーダル・ヘルプパネル・カード）: `12px`〜`16px`
  - ピル / 円形（フィルターチップ・トグル・選択チェック）: `999px` / `50%`
- **線と影**: 基本は `1px solid var(--line)` のフラットな区切り。影はフローティング要素（モーダル、スティッキーフッター、オーバーレイボタン、プライマリボタンのホバー）にのみ薄く用いる。
- **アイコン**: `20px`（小は `14px`〜`16px`）、線幅 `1.7px`、丸みのある端（`stroke-linecap: round; stroke-linejoin: round`）のラインアイコンで統一する。

---

## 5. 文字と密度の方針

- **フォント**: システムサンセリフ（`-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans JP", sans-serif`）、本文 `14px` / 行高 `1.5`。
- **数値**: 件数・寸法（px）には `font-variant-numeric: tabular-nums` を適用し、ガタつきを防ぐ。
- **密度と余白**: 4px / 8px を基本単位とし、タッチターゲットはモバイル・デスクトップ問わず最低 `44px × 44px`（または同等の当たり判定）を確保する。

---

## 6. 動きの性格

- **原則**: 素早く、控えめに、意味のある反応だけを返す。
- **トランジション**: ホバー・フォーカス・トグルは `120ms〜160ms` のイージング。押下時はわずかな沈み込み（`translateY(1px)` または `scale(0.985)`）で手応えを伝える。
- **アクセシビリティ**: `prefers-reduced-motion: reduce` の環境ではアニメーション・トランジションを無効化する。

## 7. 画面ごとの意味（主役・狙う気持ち・手段）

1. **メイン作業画面（ギャラリー）**
   - **主役**: 収集された画像サムネイル一覧と選択状態。
   - **狙う気持ち**: 「目的の画像がすぐ見つかり、テンポよく選べる」。
   - **手段**: 検索・絞り込みをコンパクトに折りたたみ、画像カードを主役に配置。下部のスティッキーフッターに「保存ボタン」を固定し、いつでも保存へ進める。
2. **拡大プレビューモーダル（`#image-preview`）**
   - **主役**: 選択・確認中の1枚の画像（＋別候補の比較）。
   - **狙う気持ち**: 「細部までしっかり見極めて、間違いなく選べる」。
   - **手段**: 背景を暗く落として画像に集中させ、スワイプ・矢印キー・等倍トグルで軽快に検品できる操作系を下部・左右に配置。
3. **保存設定ダイアログ（`#save-settings`）**
   - **主役**: 保存先（Chromeダウンロード / 選択フォルダ / ZIP）と保存形式の決定。
   - **狙う気持ち**: 「自分の望む場所と形式で、安全に保存できると確信できる」。
   - **手段**: 選択肢をカード・ラジオボタンで整理し、実際のフォルダ名プレビューと「設定を適用」ボタンで確定を明確にする。
4. **初回オンボーディングダイアログ（`#onboarding`）**
   - **主役**: 1ページ1主張の視覚カード・イラストと、ユーザーの悩み選択・ミニ試し操作。
   - **狙う気持ち**: 「自分の困りごとにぴったりの道具だとわかり、ワクワクしながら早く最初の1枚を選びたくなる」。
   - **手段**: 上部に最大5個の窓ドット進捗と戻る/スキップ、中央に面積3割以上の視覚ステージ（主役アニメーション＋最大2要素の控えめな常時アニメーション）、下部に1行の見出し・最大2行の補足・操作ボタンを配置し、選んだ回答を本体の初期状態へ引き継ぐ。
