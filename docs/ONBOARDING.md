# ImageCrate 初回オンボーディング設計・検証記録

本ドキュメントは `mobile_onboarding` スキルに基づき設計・実装した ImageCrate の初回オンボーディングの正本である。

---

## 1. コンセプトの読み取り

### 事実（リポジトリの実装・設計資料から確認）
- **コンセプト（一文）**: Webページ上の画像を集めたい人が、広告や不要な画像が混ざるページで、プレビューと絞り込みから必要な画像だけを選んで一括保存することで、探す手間なく欲しい画像だけが手元に整う体験。
- **解決する困りごとと、解決後のいちばんの変化**:
  1. **広告や小さなアイコンが混ざって探しにくい** → 広告除外フィルター（初期ON）や横幅・高さの範囲スライダーで、本文の画像だけがすっきり並ぶ。
  2. **1枚ずつ長押しや右クリックで保存するのが手間** → タップでまとめて選び、1回で一括保存（ZIP共有・選択フォルダ・ダウンロード）できる。
  3. **保存した画像の形式やフォルダ整理で困る** → 端末内で JPEG / PNG / WebP へ変換でき、ページ名のフォルダや ZIP に自動で整理される。
- **最初の小さな成功（最初に「できた」と感じる瞬間）**:
  - 一覧に並んだ画像から欲しい1枚をタップして選択マークをつけ、画面下の保存ボタンへ進める状態になった瞬間。
- **使う場面の頻度と、初回と反復利用で変わること**:
  - 記事・漫画・資料・ギャラリーなどで画像をまとめて手元に残したい場面で都度利用する。
  - 初回は「何のためのアプリか」「3ステップの基本操作」「自分の困りごとに合う使い方」が伝わることが重要。2回目以降はオンボーディングを自動表示せず、前回の保存先設定を引き継いで即座に作業台が開く。
- **競合・類似ツールとの違い**:
  - 外部サーバーやサードパーティ依存ゼロ（端末内完結・プライバシー保護）。
  - 広告・トラッカーを除外しつつ縦スクロール漫画（Webtoon）や高解像度画像を保護。
  - デスクトップ（Chrome / macOS Safari）とモバイル（iOS Safari 共有シート・ZIP一括保存・タッチスワイプ検品）の両対応。

### 設計上の仮説
- 初回起動時に「お悩みの選択（1問）」と「ミニ画像カードの試し操作（1タップ）」を挟むことで、説明を読むだけの受け身状態から「自分のための道具だ」と感じて本体の最初の1枚選びへ迷わず進める。

### 未確認事項
- 初見の人間による実機（iOS Safari / デスクトップ Chrome）での体験観察と、直後の3問ヒアリング（「何のためのアプリか」「最初に何をするか」「使ってみたいか」）。

## 2. 4つの達成条件

1. **何のためのアプリか（自分の言葉で言い直せる一文）**:
   - 「Webページの画像から、欲しいものだけを選んでまとめて保存するアプリ」
2. **基本的な使い方（ちょうど3ステップ・動詞始まり）**:
   - **ステップ 1**: `1. 画像を選ぶ`（一覧のカードをタップすると、選択マークがつきます）
   - **ステップ 2**: `2. 条件で絞り込む`（横幅・高さのバーや広告除外で、目当ての画像に絞れます）
   - **ステップ 3**: `3. まとめて保存する`（画面下の保存ボタンを押すと、選んだ画像が一括で保存されます）
3. **ワクワクする瞬間**:
   - **途中の山場**: 選んだ悩みに合わせて広告が消える／一括保存される価値ページ（#5, #6）と、本物と同じミニ画像カードをタップして選ぶ試し操作（#10）＋達成ページ（#11）。
   - **接続直前の山場**: 「欲しい画像だけが、きれいな箱に揃う」（#12 期待ページ）。
4. **早く使いたい（本体の最初の小さな成功へ直結）**:
   - 最終ページ（#13 接続）の「画像一覧を開いて選ぶ」ボタンを押すと、オンボーディングで選んだ悩みに合わせた初期設定・ヒントが反映された状態で一覧の最初の画像カードへフォーカスが移る。

## 4. インタラクションと回答の引き継ぎ

1. **悩み・希望の選択（#2 → #3 → #5/#6 → 本体初期設定）**:
   - `noise`（「広告や小さなアイコンばかり混ざって探しにくい」）:
     - #3 見出し: `「広告が混ざって探しにくい」あなたにぴったりです`
     - #5/#6 順序: 「広告を除いて、本文の画像だけ並ぶ」→「1枚ずつの保存から、1タップの一括保存へ」
     - 本体反映: 広告除外フィルターを確実にONにし、下部ヒントに `広告を除外して表示中 · 欲しい画像をタップして選択` を表示。
   - `effort`（「1枚ずつ長押しや右クリックで保存するのが手間」）:
     - #3 見出し: `「1枚ずつ保存するのが手間」なあなたにぴったりです`
     - #5/#6 順序: 「1枚ずつの保存から、1タップの一括保存へ」→「広告を除いて、本文の画像だけ並ぶ」
     - 本体反映: 下部ヒントに `複数枚をタップして「選択N件を保存」で一括保存できます` を表示。
   - `format`（「保存した画像の形式やフォルダ整理で困る」）:
     - #3 見出し: `「形式やフォルダ整理で困る」あなたにぴったりです`
     - #5/#6 順序: 「好きな画像形式で、ページ名のフォルダに整う」→「広告を除いて、本文の画像だけ並ぶ」
     - 本体反映: 下部ヒントに `下の「変更」から保存形式（JPEG/PNG/WebP）やフォルダ名を選べます` を表示し、保存先ピル（`.destination-pill`）をハイライト。
   - `unsure`（「まだわからない・まずは見てみたい」・逃げ道）:
     - #3 見出し: `まだ決まっていなくて大丈夫です`（断定しない誘いの文言）
     - #5/#6 順序: 標準順
     - 本体反映: `気になる画像をタップして選択できます` を表示。
2. **ミニ画像カードの試し操作（#10 → #11 → 本体フォーカス接続）**:
   - 3枚のミニカード（風景のメイン写真 / 記事のイラスト / 解説の図表スライド）から1枚をタップすると、中段階の反応（320ms）ののち自動で #11 へ進み、選んだカード名を反映した達成画面を表示。
   - 完了時（#13）に本体ギャラリーの最初の画像カードの選択チェックへフォーカスを移動し、1タップで最初の成功へ直結させる。
