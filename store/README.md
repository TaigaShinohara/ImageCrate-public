# ストア用の素材

Chromeウェブストアへは、ここからは送信しません。ダッシュボードへ自分で貼る原稿と、アップロード用の画像だけを置いています。

| ファイル | 用途 |
| --- | --- |
| `listing.ja.md` | 掲載文（日本語） |
| `listing.en.md` | 掲載文（英語） |
| `dashboard.md` | 単一の目的、権限の理由、リモートコードを使わないこと、データの利用 |
| `screenshots/` | 1280×800の画面。合成したローカルページだけで作成 |
| `promo-small-440x280.png` | 小さいプロモーション画像（440×280） |
| `icon-128.png` | ストア用アイコン（128×128）。絵は約96×96で、周囲は透明 |

プライバシーポリシーの本文は `docs/PRIVACY_POLICY.md` です。既定ブランチに公開したあとのファイルURLを、ダッシュボードのプライバシーポリシー欄へ貼ります。URLは `dashboard.md` に書いてあります。

画面写真に実在のサイトや個人情報は入っていません。配布用zipは `npm run package` で `dist/` にでき、`dist/` はリポジトリへ入れません。
